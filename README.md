# H2-Flugzeug Business Case — interaktives Modell (G3)
Ein-Welt-Rechner auf der Mechanik eines auditierten techno-ökonomischen Modells
(Monte-Carlo-Studie, 20.000 Welten): fünf Flugzeug-Cases, Nachfrage-Gate,
Speed-Malus, nichtlineare Preispfade, realer WACC. Alle Regler tragen
auditierte Bänder; Werte außerhalb werden markiert.

**Live:** https://fritzhoffmeister.github.io/h2-tool/ (Zugriff passwortgeschützt)

Die Seiten in diesem Repo sind AES-256-GCM-verschlüsselt und werden nach
Passworteingabe lokal im Browser entschlüsselt (WebCrypto/PBKDF2). Die
Klartext-Quellen und das Build-Skript liegen im privaten Arbeits-Repo.

Studie: **Fritz Hoffmeister** — Initiator, Studienleitung & kritisches Review.
Modellierung & Umsetzung KI-gestützt (Claude, Anthropic); alle tragenden
Zahlen auditiert & reproduzierbar. Modellrechnung, keine Anlageberatung.
